# Liquid Glass Calculator

Calculadora Android científica em Kotlin + Jetpack Compose, com interface escura inspirada em Liquid Glass.

## Recursos
- Operações básicas, parênteses e porcentagem
- Potência, raiz quadrada e fatorial
- seno, cosseno, tangente, logaritmo e ln
- Alternância entre graus e radianos
- APK de debug publicado em `releases/LiquidGlassCalculator.apk`

O GitHub Actions compila o APK automaticamente a cada alteração no código-fonte.
